
#Proyecto de Cajero Automático
## Visión
**Para** clientes de Produbanco 
**quiénes** necesitan retirar efectivo de sus cuentas en cualquier momento, sin depender del horario comercial. 
**El** cajero automático de Produbanco 
**es** un canal de autoservicio bancario 
**que permite** los retiros de efectivo de cuentas de ahorros y corrientes se realizan con una tarjeta y PIN, validando la identidad del cliente y respentando el límite de retiro diario. 
**A diferencia** de los retiros en ventanilla que dependen del horario comercial y la atención de un miembro del personal 
**nuestro** producto permite retiros de efectivo 24/7 con autenticación por PIN, bloqueo después de 3 intentos fallidos y recibo de transacción.

# Objetivos
1. Evitar retiros de efectivo no autorizados en cajeros automáticos.
2. Mantener el servicio de retiro de efectivo disponible 24/7 a través de cajeros automáticos.
3. Permitir a los clientes retirar efectivo sin asistencia de una persona. 

# Capacidad
v1

1.1 El sistema puede autenticar al cliente y controlar el acceso a sus cuentas. 

1.2 El sistema puede controlar y registrar transacciones. 

2.1 El sistema puede controlar el abastecimiento de efectivo en los cajeros automáticos. (Puede unirse con la 2.2)

2.2 El sistema puede monitorear el estado del cajero automático. 

3.1. El sistema puede retirar efectivo sin que un empleado tenga que hacerlo. 

3.2. El sistema es capaz de guiar al cliente durante la operación.

v2

| OBJETIVO  | TÍTULO                                    | DESCRIPCIÓN                                                                                                        |
| --------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 1     | 1. Control de acceso         | El sistema permite autenticar al cliente y controlar el acceso seguro a sus cuentas bancarias.                     |
| 1     | 2. Gestión de transacciones                  | El sistema permite controlar y registrar las transacciones realizadas por los clientes.                            |
| 2     | 3. Monitoreo del cajero automático | El sistema permite controlar el abastecimiento de efectivo y monitorear el estado operativo del cajero automático. |
| 3     | 4. Retiro autónomo de efectivo               | El sistema permite al cliente retirar dinero en efectivo sin la intervención de un empleado.                       |
| 3     | 5. Asistencia durante la operación           | El sistema guía al cliente paso a paso durante el proceso de retiro de efectivo.                                   |

# Características

1.1.1. El sistema permite validar la tarjeta y el PIN del cliente. 

1.1.2. El sistema permite bloquear la tarjeta después de 3 intentos fallidos consecutivos. 

1.1.3. El sistema permite el cierre automático de sesión por inactividad. 

1.2.1 El sistema permite aplicar el límite de retiro diario por cliente. 

1.2.2. El sistema permite registrar cada transacción para trazabilidad. 

2.1.1. El sistema permite reabastecer efectivo en cajeros automáticos. 

2.1.2 El sistema permite el retiro de efectivo de cajeros automáticos. 

2.2.1 El sistema permite monitorear el nivel de efectivo y alerta cuando se necesita reabastecimiento. 

2.2.2. El sistema permite reportar fallas del cajero automático para atención. 

3.1.1 El sistema permite seleccionar la cuenta ahorros o corriente. 

3.1.2. El sistema permite ingresar el monto a retirar. 

3.1.3. El sistema verifica si el saldo es suficiente. 

3.1.4. El sistema permite entregar el efectivo y debitar la cuenta.
